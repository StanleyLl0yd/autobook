# Security Policy

[Русская версия](SECURITY_RU.md)

## Supported versions

Security fixes are provided for the latest published AutoBook release.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue. Use
[GitHub Security Advisories](https://github.com/StanleyLl0yd/autobook/security/advisories/new)
to send a private report.

Include the affected version, reproducible steps, expected impact, and any
sanitized supporting material. Do not attach real signing keys, passwords, or
personal vehicle records.

You should receive an acknowledgement within seven days. A validated report
will be investigated and fixed before coordinated public disclosure whenever
practical.

## Scope

AutoBook is an offline-first Android application. Reports about local database
integrity, unintended data disclosure, Android backup behavior, release
signing, dependency supply chain, and build or release workflows are in scope.
