AutoBook — приватная local-first сервисная книжка личного автомобиля. Она
хранит пробег, обслуживание, расходы и предстоящие работы без учётной записи,
backend, аналитики, рекламы и постоянного подключения к сети.

> История вашего автомобиля и всё, что будет дальше.

## Текущий объём

Исходный код версии `0.1.1` включает:

- добавление автомобиля и Dashboard;
- обновление пробега с подтверждением уменьшения и неизменяемой историей;
- сервисные события из нескольких работ;
- интервалы обслуживания по пробегу и дате;
- хронологическую историю и годовую сводку расходов;
- локальное хранение Drift/SQLite;
- русский и английский интерфейсы;
- светлую, тёмную и системную темы;
- фирменную иконку Android и splash screen;
- экран «О приложении» с версией, приватностью, лицензией и исходным кодом.

## Установка

Скачайте подписанный APK из
[последнего GitHub Release](https://github.com/StanleyLl0yd/autobook/releases/latest).
Подписанный Android App Bundle — основной артефакт для Google Play, а APK —
дополнительный универсальный пакет для прямой установки. Начиная с `v0.1.1`,
в релиз входят оба файла и общий файл контрольных сумм SHA-256.

Android может запросить разрешение на установку из браузера или файлового
менеджера. Устанавливайте только файлы, опубликованные в этом репозитории, и
сверяйте их контрольные суммы при передаче через другой сервис.

## Данные и приватность

AutoBook хранит данные в базе `autobook.sqlite` на устройстве. Release-манифест
не запрашивает доступ в Интернет. Облачный Android backup и перенос данных
между устройствами отключены, чтобы история автомобиля не покидала устройство
без явного решения пользователя.

В приложении нет учётной записи, телеметрии, SDK аналитики или рекламы, GPS,
OBD и backend. При удалении приложения локальные данные удаляются. Экспорт и
управляемая пользователем резервная копия запланированы, но пока недоступны.

## Разработка

Требования:

- Flutter 3.47.1;
- Dart 3.12 или новее;
- JDK 17;
- Android SDK 37 с target API 36 и minimum API 26;
- Android NDK 28.2.13676358.

Полная локальная проверка:

```bash
./tool/verify.sh
```

Скрипт загружает зависимости, проверяет форматирование, запускает статический
анализ и тесты, затем собирает debug APK. GitHub CI дополнительно создаёт
проверочные release APK и AAB с R8 и сокращением ресурсов, используя временный
CI-ключ. Проверяются точные SDK и Flutter ABI, каждая native-библиотека,
16 KB ELF/ZIP alignment и конфигурация page alignment внутри AAB.

## Архитектура

```text
presentation (экраны и Riverpod providers)
             ↓
domain (модели и чистые расчёты)
             ↓
data (repository и Drift/SQLite)
```

Количество слоёв намеренно ограничено. Явные Drift statements описывают схему
и миграции, а repository возвращает типизированные доменные объекты и потоки.
Стоимость сервисного события остаётся источником истины для сводки расходов,
поэтому одно событие нельзя посчитать дважды.

- [ADR-0001: архитектура прототипа](docs/adr/0001-prototype-v0.1.md)
- [ADR-0002: усиление v0.1.1](docs/adr/0002-v0.1.1-hardening.md)
- [ADR-0003: готовность к Google Play](docs/adr/0003-google-play-readiness.md)

## Целостность релизов

Подписанные релизы собираются только через
[Android Release workflow](.github/workflows/release.yml). Валидация,
сборка/подпись и публикация разделены на jobs с минимальными разрешениями.
Сторонние Actions закреплены полными commit SHA.

Workflow:

1. принимает только тег `vMAJOR.MINOR.PATCH`, совпадающий с `pubspec.yaml`;
2. проверяет форматирование, анализ и тесты;
3. сначала собирает подписанный сокращённый R8 AAB, затем дополнительный
   универсальный APK;
4. проверяет конфигурацию API 26/36/37, `armeabi-v7a`, `arm64-v8a`, `x86_64`
   и 16 KB-совместимость каждой native-библиотеки и пакета;
5. подтверждает APK Signature Schemes v2 и v3, одного подписанта APK и
   ожидаемый отпечаток сертификата APK и AAB;
6. создаёт SHA-256 и публикует новый неизменяемый GitHub Release.

Ключ поступает из защищённого окружения `release` и GitHub Actions Secrets, а
после сборки удаляется с runner. Существующие теги и релизы не перезаписываются.
