# AutoBook

[English version](README.md)

AutoBook — локальная цифровая сервисная книжка личного автомобиля. Она хранит пробег, обслуживание, расходы и предстоящие работы без обязательной учётной записи и backend.

> Вся история вашего автомобиля. И всё, что нужно сделать дальше.

## Prototype v0.1

Текущий вертикальный прототип включает:

- добавление автомобиля;
- Dashboard с пробегом, ближайшими работами и последними событиями;
- обновление пробега с подтверждением при уменьшении значения;
- обслуживание из нескольких работ;
- интервалы одновременно по пробегу и дате;
- хронологическую историю обслуживания;
- годовую сводку расходов, рассчитанную из сервисных событий;
- локальное хранение в SQLite через Drift;
- русский и английский интерфейс;
- светлую, тёмную и системную темы.

В прототипе нет backend, авторизации, телеметрии, AI, OCR, GPS, OBD, рекламы и маркетплейса.

## Требования

- Flutter 3.47 или новее;
- Dart 3.12 или новее;
- настроенный Android toolchain для Flutter.

## Запуск

```bash
./tool/verify.sh
flutter run
```

При первом запуске проверочный скрипт создаёт Android runner, загружает зависимости, форматирует и анализирует код, запускает тесты и собирает debug APK.

## Архитектура

```text
presentation (экраны + Riverpod providers)
             ↓
domain (модели + чистые расчёты)
             ↓
data (repository + Drift/SQLite)
```

Слои намеренно оставлены компактными. Схема и миграции Drift описаны явным SQL, а repository возвращает типизированные доменные объекты и потоки. Стоимость обслуживания является источником истины для экрана расходов, поэтому одно событие невозможно посчитать дважды.

Модель данных, навигация и архитектурные компромиссы описаны в [ADR-0001](docs/adr/0001-prototype-v0.1.md).

## Данные и приватность

Данные прототипа хранятся только на устройстве в `autobook.sqlite`. Сеть для работы приложения не нужна. Идентификаторы автомобилей и событий сразу представлены UUID, чтобы сохранить путь к будущей local-first синхронизации.

## Roadmap

- **v0.1:** один автомобиль, пробег, обслуживание, история, расписание ТО, расходы;
- **v0.2:** несколько автомобилей, напоминания, детали, гарантии, документы;
- **v0.3:** фотографии, экспорт PDF/CSV/JSON, простая статистика;
- **v0.5+:** опциональные зашифрованные backup и синхронизация.
