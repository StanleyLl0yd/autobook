# История изменений

[English version](CHANGELOG.md)

Здесь будут перечисляться все заметные изменения AutoBook.

## [0.1.1] — 01.09.2026

### Добавлено

- Фирменные Android launcher, adaptive, monochrome и splash assets.
- Экран «О приложении» с версией, автором, приватностью, лицензией и исходным кодом.
- Тесты схемы базы, каскадного удаления и неразрушающих миграций.
- Dependabot, структурированные формы Issues и приватный канал для уязвимостей.
- Политики безопасности на русском и английском языках.

### Изменено

- Android application ID изменён на `com.sl.autobook`.
- Минимальная версия Android — API 26, compile API — 37, target API — 36.
- Подписанный AAB стал основным Play-артефактом; APK сохранён для прямой установки.
- Native-код ограничен поддерживаемыми Flutter ARM32, ARM64 и x86-64 ABI и собирается NDK r28.
- Release APK и AAB теперь собираются с R8 и сокращением ресурсов.
- CI проверяет debug, release APK и release AAB с временным ключом.
- Валидация, подпись и публикация релиза разделены на jobs с минимальными правами.
- Сторонние GitHub Actions закреплены полными commit SHA.
- Системные панели, launcher icons и splash screen оформлены в стиле AutoBook.

### Безопасность

- Облачный Android backup и перенос локальных записей между устройствами отключены.
- Публикация релиза не перезаписывает существующие теги и Releases.
- Проверяются APK Signature Schemes v2 и v3, число подписантов и отпечатки сертификатов APK/AAB.
- CI проверяет все native-библиотеки и оба релизных формата на совместимость с 16 KB page size.
- Загрузка Gradle защищена официальной контрольной суммой SHA-256.
- Обновление базы останавливается без явной миграции и не удаляет данные.

### Примечание об обновлении

- Android считает `com.sl.autobook` отдельным приложением относительно прототипа
  `v0.1.0` (`com.silverlightning.autobook`). Установка и локальные записи
  `v0.1.0` не обновляются и не переносятся автоматически.

## [0.1.0] — 26.08.2026

### Добавлено

- Начальная архитектура local-first Flutter-прототипа.
- Добавление автомобиля и Dashboard.
- История пробега с подтверждением при уменьшении значения.
- Сервисные события из нескольких работ.
- Расчёт следующего обслуживания по дате и пробегу.
- Хронологическая история и годовая сводка расходов.
- Локальное хранение Drift/SQLite без backend.
- Ресурсы русской и английской локализации.
- Основа светлой, тёмной и системной тем.
- Unit-тесты расчётов обслуживания, пробега и расходов.
